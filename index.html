Own project · 2025 – now

Snyptly

A web app that turns long videos from YouTube, Twitch and Kick into short clips ready to post. Paste a link, Snyptly finds the best moments, and you trim, crop to 9:16, add captions and download.

  • Accounts with Google sign-in, password reset and an admin panel
  • Migrated the app from Vite + Web Components to Next.js

How it finds the best moments

The clip detection doesn’t use an AI model. Snyptly scores a signal for each source itself, starts each clip just before the peak and snaps it to sentence boundaries, so clips don’t cut off mid-word.

I did use AI tools as a coding assistant while building the app. The detection logic itself is plain code.

YouTube: emotion in the transcript

Every line gets a sentiment score, with extra points for words like “insane” or “no way”.

Twitch: chat spikes

It looks for moments when the chat suddenly gets much busier than usual.

Kick and uploads: loudness

FFmpeg measures the audio, and Snyptly picks the loudest peaks above the normal level.
